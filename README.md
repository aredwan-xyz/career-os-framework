## What This Is

Most job searches are chaotic and reactive. This system makes them structured and proactive.

**Career OS** is an 8-module framework with:
- Actionable playbooks for every stage of the job search
- 40+ ready-to-use AI prompts (Claude / ChatGPT compatible)
- Word-for-word scripts for outreach, interviews, and negotiation
- Templates for CVs, cover letters, tracking, and STAR stories
- A full automation stack and weekly cadence system

Whether you're starting from zero or optimizing an active search, this repo gives you everything in one place.

## Quick Start

```bash
git clone https://github.com/yourusername/career-os.git
cd career-os
```

**Recommended path:**

1. Start with [`docs/01-identity.md`](docs/01-identity.md) — don't skip this
2. Build your master CV using [`templates/master-cv.md`](templates/master-cv.md)
3. Set up your tracking system using [`templates/job-tracker.md`](templates/job-tracker.md)
4. Run the daily cadence in [`docs/08-cadence.md`](docs/08-cadence.md)
5. Use [`prompts/`](prompts/) for every AI-assisted task

## Key Principles

**1. Specificity is leverage.**
"Senior engineer" competes with 50,000 people. "Senior ML engineer who reduces inference costs for LLM startups" competes with 40. Define your niche.

**2. Referrals convert 9x better than cold applications.**
Spend 40% of your effort on warm outreach, even to people you barely know. One well-placed message beats 50 cold applications.

**3. Signal building never stops.**
30 min/day on LinkedIn content compounds into inbound recruiter messages every week — without applying to anything.

**4. Never accept the first number.**
Negotiating $10,000 more in base salary is worth $500,000+ over a 20-year career when you account for raises, bonuses, and future offers anchored to this number.

**5. The system compounds.**
Every module you complete makes your next search faster, warmer, and better-paid than the last.
