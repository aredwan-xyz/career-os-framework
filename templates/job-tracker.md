## Stage Definitions

| Stage | Meaning |
|-------|---------|
| `Prospect` | On target list, not yet applied |
| `Applied` | Application submitted, no response |
| `Screened` | Initial email/phone screen completed |
| `Interview 1` | First full interview done |
| `Interview 2` | Second round |
| `Final` | Final round / panel / case study |
| `Offer` | Offer received |
| `Negotiating` | In negotiation |
| `Accepted` | Offer accepted |
| `Rejected` | Declined or passed |
| `Stalled` | No response in 20+ days, not actively pursuing |
| `Withdrawn` | You withdrew |

# STAR Story Bank Template

> Build 15 stories. Update after every significant achievement.

---

## Story Format

```
STORY #[n] — [Short title, e.g. "Fraud detection system rebuild"]

Tags: [R/T/L/P/C/D] 
Interview questions this answers: [list 3–5 question types it covers]
Estimated tell time: [target: 60–90 seconds]

SITUATION (1–2 sentences)
Context: [Company stage, team size, challenge you inherited or faced]
Stakes: [Why this mattered — what was at risk]

TASK (1 sentence)
Your specific responsibility: [what you were personally accountable for]

ACTION (3–5 sentences — the most detailed section)
- What you did first
- Key decisions you made (and why)
- How you collaborated or led
- What obstacle you overcame

RESULT (2–3 sentences)
- Primary metric: [e.g. "Reduced fraud loss rate from 2.3% to 0.8%"]
- Secondary impact: [e.g. "Freed 3 ops analysts from manual review"]
- Timeframe: [e.g. "within 4 months of starting"]

WHAT I'D DO DIFFERENTLY
[1 sentence — shows self-awareness, good for "failure" question variants]
```
